# Daily video — build brief, phase 1 (look + sample renders)

Read `docs/VIDEO.md` first: it is the product plan. This brief is the exact spec for **phase 1 only**:

- a new package `packages/video` that turns real Zaviya articles into a fully animated 30-second
  vertical MP4 with Remotion
- 4 sample videos for review

Phase 1 has no worker, queue, Docker, posting or website work.

## Hard rules (read twice)

1. **Allowed paths**:
   - you may create and edit files inside `packages/video/` only
   - you may also add `packages/video/out/` and `packages/video/fixtures/images/` to the root `.gitignore`
   - `pnpm install` will update `pnpm-lock.yaml`, which is expected
2. **Never** touch `apps/*`, `infra/*`, `docker-compose*.yml`, other packages, the server (`ssh` of any kind), git remotes.
   Never deploy, push, or post anything to any social platform.
3. **Git**: first run `git switch -c feat/daily-video` (untracked files in the repo come along; leave them alone).
   **Do not commit.** The reviewer commits after checking.
4. **Network**: only reading `https://zaviya.pk/api/...` (public JSON, our own site), its image URLs, and npm installs.
   Remotion downloads its own chrome-headless-shell and ships its own ffmpeg/ffprobe, so do not install system ffmpeg.
5. **No AI/LLM calls and no randomness**: everything is a deterministic function of the input. Use `random(seed)` from `remotion`, never `Math.random`.
6. **No copyrighted music**: the sample audio is synthesized by our own script (see Audio).
7. If something in this brief turns out to be impossible or wrong, choose the closest safe option, keep going, and list the deviation in your final report. Don't stop silently or invent features.

## compose.ts rules (pure, fully unit-tested)

- **Stories**: take at most 5 in input order (the fixture script already ordered them).
  - Fewer than 3 stories: throw `NotEnoughStories`.
  - 3 or 4 stories: the remaining time goes to the scenes, so the video is still 30 s.
- **Mode**:
  - `breaking` if any story `isBreaking` or `priority==='breaking'`. That story moves to position 1.
  - else `sombre` if `isSombre(lead.title)`.
  - else `normal`.
- **Theme**: breaking gives `breaking`, sombre gives `sombre`, morning gives `sunrise`, evening gives `night`.
- **Track**: `trackId` if given; else, by mood (morning → bright, evening → night, sombre → calm, breaking → night), pick `tracks[dayOfYear % n]` of that mood.
- **Beat grid**: `beat = round(FPS*60/bpm)` frames (15 at 120 BPM).
- **Durations** (in frames, then snapped to the nearest beat):
  - hook 45 (1.5 s)
  - outro 105 (3.5 s)
  - numbers 105 (3.5 s), only when at least 2 rate tiles are valid (observed within 36 h); else omitted
  - stories share the rest, weighted by `clamp(wordCount/3 + 1, 3.5, 5.0)` seconds; the lead story gets +1 beat
- **Total**: `sum(scene durations) - transitionFrames * (scenes.length - 1)` must equal exactly **900**, because transitions overlap.
  - Use `transitionFrames = 8`.
  - Give any rounding remainder to the lead story.
  - Test that the sum is exactly 900 for 3, 4 and 5 stories, with and without numbers.
- **Scene order**: hook, S1, S2, S3, S4, numbers (if present), S5, outro. With fewer stories, numbers goes before the last story.
- **Numbers tile formatting**:
  - `USD/PKR 276.98`
  - `Gold 24K Rs 432,151 /tola`
  - `Petrol Rs 386.30 /L`
  - delta compares against `previous`; `flat` if there is no previous value or the change is < 0.05%
- **Dates** (`hijri.ts`): `dateLine` is like `SAT 17 OCT · 6 JUMADA I`.
  - Use Intl with `timeZone: 'Asia/Karachi'` and the `en-u-ca-islamic-umalqura` calendar.
  - Uppercase the result and strip "AH" and the year.
  - Test: `2026-10-17T03:00:00Z` → `SAT 17 OCT · 6 JUMADA I`.
- **Hook title**:
  - morning: `['5 STORIES', 'TO KNOW TODAY']`
  - evening: `['TODAY IN', '30 SECONDS']`
  - breaking: `['BREAKING', 'AND 4 MORE']`
  - use the real story count instead of 5 or 4
- **Outro**: `cta = 'Which story matters most? Comment 1–' + n`, `handles = HANDLES` (constant `['@zaviya.pk']`), `site = 'zaviya.pk'`.

### text.ts

- `shortenHeadline(t, max=70)`:
  1. If `t.length <= max`, return t.
  2. Otherwise cut at the last `: ` or ` — ` or ` - ` or `, ` boundary that leaves 30..max chars.
  3. Otherwise cut at the last space before max.
  4. Never end on a stop word (a, an, the, of, to, in, on, for, and, as, at, by, with, from). Strip trailing punctuation. Never add an ellipsis.
- `findFigure(t)`:
  - Return the first money/number token: `Rs\s?[\d,.]+\s?(bn|m|tr|trillion|billion|million|crore|lakh)?`, `\$[\d,.]+\s?(bn|m|tr)?`, `[\d.]+%`, or a number ≥ 2 digits with a unit word.
  - `label` = the next 2–4 words after the token in the headline, uppercased, or the category label.
  - Return null if there is no token.
  - Example: "Auto financing in Pakistan climbs 33.61% YoY to Rs407bn" gives value `Rs407bn` (prefer money over %).
- `findHighlight(t)`:
  - the figure token if there is one
  - else the longest capitalised multi-word proper noun not at position 0 (for example "State Bank")
  - else undefined
- `isSombre(t)`: case-insensitive word match on `killed, kills, dead, dies, died, death, martyr, martyred, blast, bomb, attack, terror, earthquake, flood, floods, crash, injured, wounded, funeral, mourning, shooting, suicide`.
- **Credit**: the names of sources with tier ≤ 2, de-duplicated, at most 2, joined with ` · `, prefixed with `via `. Skip names that are "Google News" or empty.

## Visual spec (1080×1920, 30 fps)

All motion comes from `useCurrentFrame()` + `spring()` / `interpolate()` with `extrapolateLeft/Right: 'clamp'`.
No CSS transitions or animations. Use `<Img>` from remotion for images (it waits for loading). The safe area is
64 px left and right, 220 px at the bottom and 180 px at the top: platform UI covers those areas, so no key text may sit there.

**Persistent chrome** (above all scenes, hidden during the hook's first 15 frames and the outro):

- logo mark + "zaviya" top-left (scale 0.8, 85% opacity)
- `ProgressBar` at the top: one segment per story, 6 px tall with 8 px gaps, at 120 px from the top; the current segment fills linearly over its scene

**Transitions**:

- `TransitionSeries` from `@remotion/transitions` with a **custom `YellowWipe` presentation**: a diagonal (15°) brand-yellow band sweeps across over 8 frames and reveals the next scene behind it.
- Sombre theme: a plain `fade()` instead.
- Breaking theme: the band is red.
- A whoosh SFX `<Audio>` starts at each transition (not in sombre mode), at volume 0.35.

**Themes**:

| Theme | Background | Overlay | Accent |
|---|---|---|---|
| sunrise | `#081410` | warm overlay | yellow |
| night | `#0B1630` (navy) | overlay | yellow |
| breaking | dark | overlay | red `#E5231B`, plus a ticker strip |
| sombre | `#111` | — | desaturated white |

In sombre mode the springs use damping 200 (no bounce) and the photos are 30% desaturated.

**Hook** (45 f):

- The lead photo is full-bleed (blurred 30 px, darkened 55%), slowly zooming.
- Title line 1 and line 2 are Unbounded 900, about 120 px, uppercase. They rise word by word with spring stagger (3 f).
- The accent colour sweeps behind line 2 (HighlightSwipe).
- The `dateLine` is in Space Mono 700 at 34 px, in a white pill; it "slams" in at frame 12 (scale 1.4 → 1 with a spring), with a tick SFX.
- Breaking: a pulsing red dot plus a "BREAKING" pill.

**Story** (`PhotoPanel` + text):

- **Background**: the same photo, cover-fit, blurred 40 px, darkened, plus a theme gradient.
- **Photo panel**: the sharp photo in a panel 1080 wide × 860 tall at the top (y 0..860). This is only about 1.5× upscale of the 1024×572 hero, which is acceptable; full-height cover would be about 3.4× and look blurry, so don't do that.
  - Ken Burns: scale 1.0 → 1.10 over the scene, with a slow horizontal pan of ±40 px whose direction alternates by index.
  - The panel's bottom edge fades into the background with a 200 px gradient.
- **Badge** at (64, 900): `index/total` in Space Mono 32 px, black on accent, pops with a spring at frame 4.
- **Category chip** next to the badge: the label uppercased, background = category colour, white text, slides in from x−40 with opacity at frame 6.
- **Headline** (`KineticHeadline`):
  - Inter 900, `letter-spacing -0.03em`, `line-height 1.02`.
  - Font size from `fitText` / `measureText` (`@remotion/layout-utils`): the largest size from 96 down to 60 that fits 952 px width in at most 4 lines. Wrap by measuring words yourself, so the lines are deterministic.
  - The words rise from 40 px below with opacity, staggered 2 f per word, starting at frame 8.
  - The `highlight` words get the `HighlightSwipe`: an accent-colour rectangle that scales X from 0 to 1 behind the words at 55% of the scene, with the text turning black on top of it.
- **Urdu subline**: if `headlineUr`, under the headline in Noto Nastaliq 700, 48 px, `direction: rtl`, `line-height 1.9`; fades in at frame 20.
- **Figure**: if present, a `CountUp` of the numeric part from 0 to the value over 20 frames, in Unbounded 900 at 110 px, accent outline (`-webkit-text-stroke`), placed between the chip and the headline. The label is in Space Mono 26 px. Keep the original formatting (prefix "Rs", suffix "bn" or "%") and count only the number.
- **Credit**: Space Mono 24 px, 75% white, at y ≈ 1620; fades in at frame 24.
- **Exit**: handled by the transition.

**Numbers** (105 f):

- Title "NUMBERS TODAY" in Unbounded 72 px.
- 3 tiles stacked, each sliding in from the right with a 6 f stagger.
- Each tile has the label (Space Mono 28), a CountUp value (Inter 900, 88 px), and a ▲ green `#2BD576`, ▼ red `#FF5A5F` or ● grey delta.
- The source is in tiny mono at 50% opacity.

**Outro** (105 f):

- The CTA text kinetic, then 1–n numbered chips popping on beats.
- Then 5 social icons popping one per beat, the handle `@zaviya.pk` large, and "Full stories → zaviya.pk".
- The final 10 frames cross-fade to the hook's background colour, so the loop is seamless.

**Cover still** (`Cover.tsx`, 1080×1920): the lead photo panel, then "TODAY · 17 OCT" (or "TONIGHT · 17 OCT" for the evening edition) in Unbounded, the number of stories, and the logo. Render it with `renderStill`.

## Audio (placeholder, synthesized, our own)

`scripts/make-audio.ts` writes 16-bit 48 kHz stereo WAVs with plain Node (build the PCM buffer yourself; no deps).
Each music file is 32 s long.

| File | Content |
|---|---|
| `bright-120.wav` | 120 BPM: soft kick on every beat, closed-hat noise ticks on off-beats, a warm sine/triangle chord pad cycling I–V–vi–IV (C major) |
| `night-110.wav` | 110 BPM, minor key, slower pad, lighter kick |
| `calm-80.wav` | 80 BPM pad only, no drums |
| `whoosh.wav` | 0.4 s band-passed noise sweep |
| `tick.wav` | 0.05 s click |
| `pop.wav` | 0.08 s sine blip |

- Apply short fade-ins and fade-outs, and normalise peaks to −3 dBFS. Keep it pleasant and quiet; it's a placeholder until licensed tracks arrive.
- Write `tracks.json` with the bpm and `firstBeatMs: 0`.
- In the composition, the music fades in over the first 10 frames and out over the last 20, at volume 0.6.

## fetch-fixtures.ts

1. Fetch the latest 40 published articles and the data points.
2. **morning.json**:
   - articles published in the 14 h before the newest article's time
   - ordered `priority high` first, then newest
   - only those with a hero image
   - at most 1 per category, except `pakistan` (2)
   - de-duplicated by naive same-story (lowercase title word overlap ≥ 50% means the same story; keep the first)
   - take 5
   - `date` = now
3. **evening.json**: the same rules with an offset, i.e. skip the stories used in morning where possible, so the two look different.
4. **breaking.json**: a copy of morning with story 2 set to `isBreaking: true`.
5. **sombre.json**: a copy of evening with the lead title replaced by a test title "Five killed as flood waters hit Swat valley villages" (marked `"_test": true`), to exercise the mode.
6. Download each hero image to `fixtures/images/<id>.<ext>`. In the JSON, set `image` to a path served by `staticFile`: copy the images into `public/fixtures-images/` (gitignored) and use `staticFile('fixtures-images/<file>')` at render time; store just the file name in the JSON.
7. Rates: the latest value per series plus the previous distinct value as `previous`.
8. Also try `locale=ur` for the same ids and fill `titleUr` when it is not null.

## render-samples.ts

1. `bundle()` once (entry `src/remotion/index.ts`).
2. For each fixture:
   - `compose()`

## qa.ts

For each MP4, run Remotion's bundled ffprobe (`npx remotion ffprobe` or `getVideoMetadata` from `@remotion/renderer`) and check:

- duration 29.5–30.5 s
- 1080×1920
- h264, yuv420p
- an AAC audio stream is present
- 30 fps
- size < 40 MB

Write `out/qa.json` and print a pass/fail table. Exit 1 if any check fails.
